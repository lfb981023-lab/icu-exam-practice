# 重症医学每日练习

在线地址：[重症医学每日练习](https://icu-study-practice-300.onrender.com)。无需登录，可将链接转发给同学使用。

网站提供两套独立题库：

- **原创模拟题：300 题。** 覆盖指定教材 60 章，包括 180 道单选和 120 道多选。保留原有题目、解析、教材摘录和 PDF 页码。
- **历年真题（用户提供）：622 题。** 从《危急重症题.doc》导入，保留原文件中的重复题号及各题来源位置；其中 563 题按原文件给出的答案核对；其余 59 题已逐题补充参考答案、核对说明和教材页码或权威网页依据。29 题可按参考答案判分，另外 30 题因文字残缺、选项歧义或版本差异给出条件性结论并保留不计分。另保留 42 条补充复习笔记。

“历年真题”是用户提供资料的分类名称，考试来源未经独立认证。普通导入题的反馈表示与原文件答案是否一致；补充参考答案的题会单独标明判分依据，原题和原标记仍可对照。59 道疑义题已作针对性核对，其余原文件答案未经过完整的现代医学准确性审核。含年代性标准的题在参考说明中注明版本。原题及答案在作答后显示，便于回查。

两套题库分别提供筛选、随机练习、错题复习和学习进度，练习队列与错题不会混合。更新兼容原 300 题的浏览器答题记录；重置记录只影响当前选中的题库。可勾选“只看补充参考答案”集中复习这 59 题；条件性答案不进入正确率和错题统计。

## 手机桌面入口

网页上方的“添加到手机桌面”入口会按手机类型显示操作步骤。安卓支持浏览器安装提示；iPhone/iPad 可在 Safari 分享菜单中添加到主屏幕。桌面名称为“重症刷题”，以独立窗口打开，仍无需登录。

首次在线成功缓存完整页面与两套题库后，可离线打开和答题；外部参考资料链接仍需联网。缓存失败不会阻止在线练习。部分系统会为桌面版分配独立存储，原浏览器记录不会被删除，但不保证自动迁移。

站点采用完整版本缓存，避免脚本与答案数据跨版本混用。后续每次修改页面、脚本或题库，须同时更新 `sw.js` 的 `CACHE_VERSION`、预缓存地址，以及 `index.html`/`app.js` 中对应的资源版本。更新保持正常 Service Worker 生命周期，新版本下载后等待旧题库窗口关闭再启用，不强制刷新正在答题的页面。

## 部署到 Render

此目录是已运行的 Render 静态网站源码。现有服务使用 GitHub 仓库的 `main` 分支。每次提交后需确认 Render 已为新提交启动部署；若未收到自动触发，应在确认没有排队或进行中的部署后发布最新提交。当前配置：

- 构建命令：`node --test tests/core.test.js`
- 发布目录：`dist`
- 无需启动命令、数据库或服务器进程。

仅 `dist` 中的文件会公开提供访问。Render 静态网站使用全球 CDN，无需配置服务器区域或计算套餐。静态托管纳入账号的流量及构建额度；请以控制台显示的套餐和额度为准。

## 验收

先确认构建测试通过，再在部署地址检查题库切换、单选与多选、解析与原文展开、待核对题不计分、错题隔离及刷新后的进度保存。原 Render 地址已由用户在关闭 VPN 的手机上确认可打开并答题；各地网络的实际访问情况仍以使用时为准。

学习进度保存在当前浏览器、当前网站域名下。此次更新保持原域名，兼容旧记录；不同浏览器或设备之间不会自动同步，清除网站数据会清除本机进度。

## 本地验证

运行 `npm test` 检查两套题库的数据、判分、待核对题和错题逻辑。预览网站可运行 `python3 -m http.server 4317 --bind 127.0.0.1 --directory dist`，然后访问 `http://127.0.0.1:4317`。

本目录不包含原教材 PDF、教材整页图片、原始 Word 文件、原托管平台的项目配置、凭证或 Git 历史。题库用于考试复习，所引资料和原答案不应直接作为临床决策依据。
