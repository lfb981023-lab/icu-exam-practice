# 重症医学每日练习

300 道原创模拟题，覆盖指定教材 60 章，包括 180 道单选和 120 道多选。支持即时判分、解析、教材摘录与 PDF 页码、章节筛选、随机练习和错题复习。

## 部署到 Render

这是独立的静态网站迁移目录，目前尚未发布到 Render。

将此目录上传到可供 Render 读取的 Git 仓库，再通过仓库根目录的 `render.yaml` 创建 Blueprint；也可手动新建 **Static Site**，使用以下配置：

- 构建命令：`node --test tests/core.test.js`
- 发布目录：`dist`
- 无需启动命令、数据库或服务器进程。

仅 `dist` 中的文件会公开提供访问。Render 静态网站使用全球 CDN，无需配置服务器区域或计算套餐。静态托管纳入账号的流量及构建额度；请以控制台显示的套餐和额度为准。

## 验收

先确认构建测试通过，再在最终部署地址检查单选、多选、知识点展开、错题和刷新后的进度保存。请使用关闭 VPN 的真实手机，在 Wi-Fi 和手机流量下验证最终题库地址；官方示例可访问不能保证新地址在所有网络中可访问。

学习进度保存在当前浏览器、当前网站域名下。切换域名后不会自动继承原网站的进度。

## 本地验证

运行 `npm test` 检查判分与错题逻辑。预览网站可运行 `python3 -m http.server 4317 --bind 127.0.0.1 --directory dist`，然后访问 `http://127.0.0.1:4317`。

本目录不包含原教材 PDF、教材整页图片、原托管平台的项目配置、凭证或 Git 历史。题库用于教材复习；年代性标准已在题干或说明中标识。

Render 官方文档：[静态网站](https://render.com/docs/static-sites)、[Blueprint 配置](https://render.com/docs/blueprint-spec)。
